## Agent skills

### Issue tracker

Issues are tracked as local markdown files under `.scratch/<feature>/`. See `docs/agents/issue-tracker.md`.

### Form designer

Adding or changing a SurveyJS toolbox item, Custom Question, property-grid setting or designer rule (`src/surveyjs/`): read `docs/agents/form-designer.md` first.

### Domain docs

Single-context: one `GLOSSARY.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
